# Changelog

## 1.0.0
Initial release of Greece Sky and Weather Nowcast.

Features:

• Real-time rainfall detection
• Adaptive machine learning model
• Probability forecasts (30 / 60 / 120 / 360 minutes)
• Rainfall quantiles (P10 / P50 / P90)
• MQTT integration
• Home Assistant compatibility
• Automatic online retraining
